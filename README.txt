操作
- 手机或电脑：按住游戏画面，拖动调整位置，松开投放。
- 按 C 查看蓝色碰撞轮廓。

个人历史分数和排行榜
- 游戏会在本机保存设备最高分，访客可设置名字；最高分在结束本局时保存。
- 账号注册要求用户名 2–18 位、密码至少 8 位。账号最高分随账号同步。
- 全服榜由同一台游戏服务器提供。连接服务器的账号和访客都会进入前 50 名最高分榜。
- 离线或直接打开 index.html 时，本机最高分仍可用；跨设备的账号分数和全服排行榜需要连接服务器。

启动共享服务器（Node.js 18 或更新版本）：
1. 解压后在游戏文件夹打开终端。
2. 运行 npm start。
3. 在该电脑访问 http://localhost:8080。其他玩家也要访问这台电脑运行的地址，排行榜才是共享的。

公开发布时，请将此 Node 服务部署到有持久磁盘的服务器，用 HTTPS 反向代理到 Node 的 8080 端口。服务器会把账号、最高分和会话密钥保存在 .private-data；部署容器需将这个目录挂载到持久磁盘。默认只需运行一个服务实例，以免本地 JSON 数据库产生并发覆盖。切勿删除 .private-data，否则游戏数据和登录会话会重置。

账号密码使用 Node.js scrypt 派生哈希保存，不以明文存入数据库。服务端数据文件应定期备份。此轻量版本没有防作弊签名；联网排行榜的分数由游戏客户端提交，适合朋友间娱乐使用。

开发者：换贴纸后运行 python tools/build_stickers.py 重新生成透明贴图与轮廓（需要 Pillow、numpy、scipy）。
游戏第三方依赖已随包附带；Node 后端仅使用内置模块，无需安装额外 npm 包。
