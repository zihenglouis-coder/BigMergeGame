# Big Merge Game

10 级人物合成游戏，支持电脑和手机游玩。

## 操作

- 电脑：移动鼠标瞄准，点击投放。
- 手机：在游戏区域按住并拖动来瞄准，移动至少一点距离后松手投放。轻触或短按不会投球。
- 按 C 显示人物碰撞轮廓。
- 下降速度略快，连续快速合成会暂时提高弹性。
- 每合成出一个 ball7，获得一次“全场爆炸”；点击游戏区右下角按钮或按 B 触发。

## 个人最高分

游戏只在当前浏览器和设备本地保存最高分，不包含账号、服务器或全服排行榜。清除浏览器网站数据会清除记录。

打开 index.html 即可游玩；游戏依赖文件已包含在此目录中。

替换贴纸后，可运行 python tools/build_stickers.py 重新生成透明贴图与人物轮廓（需要 Pillow、numpy、scipy）。
